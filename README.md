# Deep Bridge Outreach prototype

Interactive prototype of the Outreach workspace: Find customers and Find factories → contact finder → shortlist across searches → Prepare email / inquiry (attachments, signature) → Choose recipients → send / schedule → outreach tracker and Ask Factory follow-ups. Also includes Handle files.

- `prototype/Main.dc.html`: main prototype
- `prototype/Tracker.dc.html`: standalone outreach tracker board (design reference)
- `prototype/canvas.json`: canvas layout for the two boards

These are Claude Design files; they open in Claude Design, not directly in a browser.
